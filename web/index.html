WearLens Visual analytics of end-mill wear across three machine tools

Target user: process engineer introducing tool-condition monitoring on a machine fleet. In production only machine-control signals are available; the dynamometer is shown as a reference from the trial.

Guided steps:

Normalization

V1 · Wear curves per tool

VB vs cumulated contact time. Drag horizontally to filter a time range · click a panel to select the tool.

V2 · Tool life at the VB threshold analysis

Drag the dashed line = fixed replacement time.

V3 · Which signal follows wear? analysis

Spearman ρ(feature, VB) per tool and for all tools pooled (current normalization & time filter). Click a row to select the feature.

V4 · Feature vs wear

Each dot = one run. Lines = per-tool rolling median. Drag a box to brush runs. Band = feature level when tools reach the threshold.

V5 · Run timeline of analysis

Shaded bands = layers (29 runs each). Flags: J = jump vs neighbouring layers, R = rise within the layer. Click a run for details.

V6 · Run details

Click a run in V4 or V5.
