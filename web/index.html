WearLens

Can signals the machine already has — without a dynamometer — tell when to replace an end mill?

Visual analytics of end-mill wear across three machine tools. Target user: a process engineer introducing tool-condition monitoring on a machine fleet. In production only machine-control signals are available; the dynamometer is shown as a reference from the trial. The guided steps ①–④ follow the analysis: tool life → does a signal follow wear → can it set the alarm → is a jump really wear.

① Tool life — does one replacement time fit all machines?

V1 · Wear curves per end mill

VB (flank wear) vs cumulated contact time, one row per machine; dashed line = VB threshold. Drag horizontally in a panel to filter a contact-time range (updates V3 and V4); click a panel to select the end mill. VB is measured every 1–2 layers and interpolated in between.

②③ Signal — does a machine signal follow wear, and can it set the alarm level?

V3 · Which signal follows wear? analysis

Spearman ρ between the feature (current normalization, current time filter) and VB, per end mill and for all end mills pooled. Hover a cell for ρ and n; click a row to select the feature. All 8 machine-control features are listed; of the 13 dynamometer features only 2 representatives are shown (the rest are in the Feature menu). Feed axis: M1 = ball-screw motor torque [Nm], M2/M3 = linear-motor force [N], and M2 runs tool batch B, so units and batches differ across machines. Within an end mill VB is mostly interpolated from contact time, so per-end-mill ρ is optimistic.

V4 · Feature vs wear

Each dot = one run (feature after normalization vs VB). Lines = per-end-mill rolling median, line style per machine (M1 solid · M2 dashed · M3 dotted). Gray band = range of the feature level at which the end mills reach the VB threshold: this is where an alarm level would be calibrated. Drag a box to brush runs (highlighted in V1 and V5); click a dot to open the run.

④ Check — is a signal change really wear?

V5 · Run timeline of analysis

Feature per run of the selected end mill; faint bands and ticks mark layers (29 runs each). Flags: J = jump vs neighbouring layers, R = rise within the layer (computed on the raw feature). In signal-alarm mode the black line is the trailing median (15 runs), the dashed line the alarm level and ▼ the alarm. Bottom strip: VB, interpolated between microscope measurements. Click a run to open it in V6.

V6 · Run details

Signal envelopes of the selected run: machine signals (machine colour) and the dynamometer reference (gray). Faint band = detected cut; dashed lines = window used for the features. "Pin as comparison" keeps a run in light gray for comparison. Bottom: 20 ms of the raw force at 25 kHz from the nearest representative run of the same end mill (peaks = cutting edges).

Click a run in V4 or V5.

V2 · Scoreboard: replacement rules analysis

Scoreboard: every rule under the same test — mean |replacement time − time VB reaches the threshold| over the end mills that reach it; missed alarms are counted separately. Dashed line = baseline (fixed time per machine, leave-one-out). Click a rule to show it below.

Bars below: time until VB reaches the threshold; dark = used, light = unused life, hatched = overrun / late, ▼ = alarm. Drag the dashed line to change a fixed replacement time. Leave-one-out: each end mill gets the earliest life of the other end mills of its machine.
