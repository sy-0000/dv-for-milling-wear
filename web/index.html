WearLens Visual analytics of end-mill wear across three machine tools

Can signals the machine already has — without a dynamometer — tell when to replace an end mill?

Target user: process engineer introducing tool-condition monitoring on a machine fleet. In production only machine-control signals are available; the dynamometer is shown as a reference from the trial.

Guided steps:
Normalization

① Tool life — does one replacement time fit all machines?

V1 · Wear curves per end mill

VB vs cumulated contact time, one row per machine. Drag horizontally to filter a time range · click a panel to select the end mill.

②③ Signal — does a machine signal follow wear, and can it set the alarm level?

V3 · Which signal follows wear? analysis

Spearman ρ(feature, VB) per end mill and pooled (current normalization & time filter). Click a row to select the feature. Sort by

V4 · Feature vs wear

Each dot = one run. Lines = per-end-mill rolling median (M1 solid · M2 dashed · M3 dotted). Gray band = feature level when end mills reach the threshold. Drag a box to brush runs.

④ Check — is a signal change really wear?

V5 · Run timeline of analysis

Shaded bands = layers (29 runs each). Flags: J = jump vs neighbouring layers, R = rise within the layer. In signal-alarm mode: black line = trailing median (15 runs), dashed = alarm level. Click a run for details.
