## 2. 磨耗 VB 與壽命定義

- **VB**:刀腹磨耗帶寬度(flank wear land width),依 ISO 8688-2 定義。用 Keyence 數位顯微鏡(100×)量 4 個周刃,**取平均**,量測不確定度約 5 µm。
- **量測頻率**:初期和末期每層量一次,中間線性段每兩層量一次,大約每 40 個 run 才有一個實測值。其餘 run 的 VB 是依累計接觸時間 C **線性內插**而來。作者建議把 VB 解讀成「整個 run 的估計值」。
- **壽命終點**:作者自己定義為 **VB ≈ 150 µm**,從 VB ≈ 0 開始算。論文沒有說明為什麼選 150 µm;ISO 8688-2 只用來定義 VB 怎麼量。
- **典型曲線(Fig. 2b)**:一開始快速磨耗到約 50 µm,接著是線性段,最後加速。大多數 run 落在 50–100 µm 之間。

## 4. 論文列出的限制

1. **時間偏移**:力感測器和控制器訊號是用互相關對齊的,但可能殘留約 100 ms 偏差,所以不能拿來分析進出刀的時間點。
2. **M2(T4–T6)混疊**:控制器的低通濾波器被關掉,導致 force_axis 和 torque_spindle 可能失真。
3. **T7、T8 座標旋轉**:XY 平面旋轉約 1–2°,影響 position、position_control_deviation、force_axis。
4. **T8 缺少初期資料**:第一個可用的 run 就已經是 C = 177 s,VB = 34 µm。
5. **R 會跳號**:被刪掉的 run 不計入編號,所以要用 C 當時間軸,不要用 R。
