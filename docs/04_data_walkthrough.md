# 資料導覽:資料裡到底有什麼、怎麼來、我做了什麼

圖:`docs/figs/walk_1_anatomy.png`、`walk_2_F5_normalization.png`、`walk_3_F7_anomalies.png`(由 `scripts/walkthrough_figs.py` 產生)

## 1. 實驗在做什麼(由大到小)

```
3 台機台 (M1, M2, M3),跑同一支 NC 程式、同樣參數
 └─ 每台磨 3 把新刀 (T1–T9),每把刀用自己的一塊工件
     └─ 一塊工件一層一層往下切,每層深 2 mm (ap)
         └─ 一層 = 44 刀直線側銑,每刀往 +X 平移 4 mm (ae)
             └─ 一刀 = 一個 run = 一個 .h5 檔
                 刀沿 +Y 走過 100 mm 長的工件,約 4 s 在吃刀
```
- **run 不是時間**,是「第幾刀」的編號,被刪掉的刀不算進去。真正的時間軸是 **C(累計接觸時間,秒)**,也就是這把刀到這一刀開始前,總共在材料裡切了幾秒。
- **VB** 是刀刃後刀面磨出來的那條帶子的寬度,4 片刃各量一次再平均。要停機把刀拿到顯微鏡下量,所以每 1–2 層(約 40 刀)才量一次,中間的刀都是用直線內插補出來的。
- 刀切到 VB ≈ 150 µm 就算壽命結束,實驗停止。

## 2. 座標 x、y、z 的意思(walk_1 圖 a、b)
| 座標 | 在一個 run 內 | 在 run 與 run 之間 | 用途 |
|---|---|---|---|
| **y** | 從 −8 mm 等速增加到 108 mm,斜率 26.5 mm/s,也就是進給速度 1,592 mm/min | 每刀都一樣 | 確認是穩定往前切;進刀和出刀的時間點 |
| **x** | 固定不動 | 每刀 +4 mm(11 → 163 mm),換層時歸零 | **判斷這一刀在這一層的哪個位置**,並由 x 歸零切出「層」 |
| **z** | 切削時固定在 −2 mm,頭尾抬起 | 每層都是 −2,看起來是每層重新歸零的相對座標(我的推論) | 確認切深;判斷刀何時下降、抬起 |

所以 x、z 不是在描述「穩定向前」,y 才是。x 告訴你在層內第幾刀,z 告訴你切深。
另外,刪掉的刀在 x 上看得到缺口:x = 39–55 和 115–131 mm 是工件安裝孔的位置,每層頭尾的刀也被刪了。所以每層實際只剩 29 刀。

## 3. 「每秒切多少」是怎麼量的?
**沒有感測器在量「切了多少材料」。** 切多少是 NC 程式事先決定的:
- 每秒去除的體積 = 切寬 × 切深 × 進給速度 = 4 mm × 2 mm × 26.5 mm/s ≈ 212 mm³/s,全程固定。
- C(接觸時間)是作者事後依據位置訊號算出的進給速度把每刀切開,再把每刀的切削時間累加起來(論文 Sec. 3)。細節論文沒有寫,這是我依論文描述做的理解。

實際在「量」的是**切削時的反應**,也就是力、扭矩和位置誤差,見下一節。

## 4. 每個訊號是什麼、怎麼來的
| 訊號 | 物理意義 | 怎麼量的 | 取樣 |
|---|---|---|---|
| force_sensor_x/y/z | 刀推工件的力(X:橫向;Y:進給方向;Z:垂直) | 工件鎖在 Kistler 9257B **壓電測力計**上,經電荷放大器(10 kHz 低通),再由 NI 9215 轉成數位訊號 | 25 kHz |
| torque_spindle | 主軸轉動刀具要出多少扭力 | 機台控制器內部的驅動數值,一般是由馬達電流換算而來(這是通則,論文沒有細說) | 500 Hz |
| torque_axis_x/y/z(M1) | 進給軸馬達出的扭力(滾珠螺桿是旋轉馬達,所以是扭矩) | 控制器 | 500 Hz |
| force_axis_x/y/z(M2/M3) | 進給軸馬達出的推力(線性馬達直接推,所以是力) | 控制器 | 500 Hz |
| position_control_deviation_x/y | 命令位置 − 實際位置(跟隨誤差),切削阻力越大,誤差可能越大 | 控制器加編碼器 | 500 Hz |
| tool_position_x/y/z | 刀具中心在工件座標中的位置 | 控制器加編碼器 | 500 Hz |

兩個重點:
- **測力計和機台訊號是兩套獨立的量測系統。** 同一件事兩邊都看到,比只有一邊看到可信得多(F7 用到這點)。
- **刀齒頻率 530 Hz 高於機台訊號能記錄的上限(500 Hz 取樣 → 250 Hz)。** 機台訊號看不到單一刀刃的切削脈衝,只有測力計看得到(walk_1 圖 d)。這也是 M2 濾波器關掉後會混疊的原因。

## 5. 我萃取了什麼、做了哪些處理(`scripts/extract_features.py`)
每個 run 的處理流程:
1. **讀檔**:讀 h5,只讀取不修改。
2. **找切削區段**:測力計 XY 合力的 50 ms 移動 RMS,超過其 95 百分位數的 30% 就算在吃刀(walk_1 圖 b 淺綠)。
3. **裁掉頭尾各 0.15 s**(walk_1 圖 b 深綠):避開進刀、出刀的衝擊,以及力和控制器訊號之間約 100 ms 的時間偏移。
4. **在這段時間內算統計量**:

| 類別 | 特徵 | 意義 |
|---|---|---|
| 力的大小 | Fx_mean、Fy_mean、Fz_mean、Fxy_mean、Fxy_rms、F3_mean、Fxy_p99 | 平均切削力、合力、尖峰 |
| 力的波動 | Fx_std、Fy_std、Fz_std | 切削力上下起伏的程度 |
| 頻率 | A_tooth(530 Hz)、A_spindle(133 Hz)、runout_ratio = A_spindle / A_tooth | 刀刃每次切入的力脈衝大小;4 片刃是否平均 |
| 進出刀 | entry_peak、exit_peak | 切入、切出瞬間的最大力 |
| 主軸 | Tsp_mean、Tsp_std | 主軸扭矩(取絕對值,因為各機台的正負號慣例不同) |
| 進給軸 | ax_x_mean、ax_y_mean、ax_z_mean、ax_y_std | 進給馬達出力 |
| 位置誤差 | pcd_x_std、pcd_y_std | 跟隨誤差的波動 |
| 背景資訊 | x_pos_mm、cut_s、layer | 層內位置、切削長度、第幾層 |

5. **核對**:檔案內的標籤和 filelist.csv 逐列比對,6,418 列全部一致;偵測到的切削長度為 3.91–4.05 s,和「每刀約 4 s」相符。

接著在 `scripts/eda.py` 做:
- **依刀具正規化**:每個特徵除以該刀在 VB 50–60 µm(磨合期結束後)的中位數,得到「相對於這把刀穩定期的倍數」。
- **Spearman 相關**:分別計算每把刀的特徵 vs VB,以及 9 把刀合併後的特徵 vs VB、特徵 vs C。
- **去趨勢殘差**:每個值相對於前後約一層(29 個 run)的滑動中位數的偏差,用來找層內效應和異常。

## 6. F5 詳解:同一個特徵,換一台機台還能用嗎?(walk_2 圖)
**問題**:工程師在 M1 上學會「主軸扭矩到多少就該換刀」,這個經驗能直接搬到 M2、M3 嗎?
- **圖 a(原始值)**:同樣在 VB 50–60 µm,主軸扭矩 M1 約 1.22 Nm、M2 約 1.35、M3 約 1.03,起點不同。到 VB 135–150,M1 約 1.58、M2 約 1.77、M3 約 1.27。所以絕對門檻不能跨機台使用,例如「1.5 Nm 就換」在 M3 上永遠不會觸發。
- **圖 b(除以各刀自己的參考值)**:三台的曲線疊在一起,VB 135–150 時都約 1.22–1.31 倍。意思是改用「相對於這把刀穩定期上升了多少%」,經驗就有機會跨機台使用。
- **圖 c(530 Hz 刀齒振幅,同樣處理)**:M1、M2 隨磨耗上升約 1.7–1.9 倍,**M3 反而下降到約 0.74 倍**。所以同一套方法對這個特徵不適用,而且原因不明(可能和 M3 的機台動態或座標旋轉有關)。
- **Fxy_mean** 介於兩者之間:M1、M2 約 2.2–2.4 倍,M3 只有約 1.5 倍。

**結論**:每個特徵、每台機台都要個別判斷「能不能信、要怎麼正規化」,這需要人看圖、比較。這就是 VA 的用武之地,不是單一數字能回答的。

## 7. F7 詳解:兩個「看起來不像磨耗」的段落(walk_3 圖)
淡橘色和白色交替的區塊代表不同層。上排是測力計合力(黑)和機台主軸扭矩(彩色)兩個獨立來源,下排是頻率特徵。

**T9(圖 a1、b1)**
- 第 10–14 層裡,每一層的切削力都從約 360 N 一路升到約 570 N,下一層開頭又掉回去,形成鋸齒。
- 主軸扭矩也同步出現鋸齒(相關 0.94,每層上升 5–7%)。兩套系統都看到,所以不是感測器故障。
- 磨耗不會倒退,但力每到新的一層就重置,所以這段的力變化**不全是磨耗**。
- 換層時剛好會停機去量 VB,所以熱狀態或裝夾可能改變,但這只是推測,沒有紀錄可以證實。
- ⚠️ 之前說「忽大忽小、不穩定」是錯的,看了圖才發現是規律的鋸齒,已在 03_eda.md 修正。

**T1(圖 a2、b2)**
- 第 15 層第一刀起,力和扭矩同時跳高約 20–30%;530 Hz 振幅從約 130 跳到約 230 N;runout_ratio 從約 0.13 降到約 0.08。
- 第 16 層力回落,但頻率特徵沒有回到原本的水準,表示刀發生了某種持續的改變。
- 可能是刃口崩缺,或重新裝夾後偏擺改變。同一時間 VB 的斜率也變大(1.4 → 2.7 µm/min),但同樣只是推測。

**對使用者的意義**:如果只看一個特徵的數字,工程師會以為 T1 在第 15 層突然磨很快,或 T9 的磨耗忽快忽慢。必須點進去看兩種訊號是否一致、是否和換層同步,才能判斷是不是真的磨耗。這就是「需要人判斷」的具體例子。

## 8. 一併修正 F6
同一層內刀永遠由 x 小切到 x 大,所以「層內位置」和「層內時間」完全同步。之前叫它「位置效應」並不精確,應該稱為**層內效應**,原因可能是位置或時間(例如升溫),這份資料無法區分。
