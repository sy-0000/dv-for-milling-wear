# 階段 6:視覺設計方案(待選)

決定事項(已確認):目標使用者 = **在多台機台導入刀具監控的製程/設備工程師**;設定 = **產線上沒有測力計**。
所以系統的主要指標只用**機台控制器訊號**(主軸扭矩、進給出力、位置誤差)。測力計只在「導入前的試驗資料」中作為**參考答案**,用來驗證機台訊號,並在下鑽時對照。

線框圖:`docs/figs/stage6_optionA.png`、`docs/figs/stage6_optionB.png`

## 共用設計(兩案相同)

### 全域控制列(一列,放在最上方)
| 控制 | 選項 | 對應任務 |
|---|---|---|
| 訊號來源 | 只看機台訊號(預設) / 加入測力計參考 | 設定「產線無測力計」 |
| 特徵 | 下拉選單,預設 Tsp_mean | T3–T7 |
| 正規化 | 原始值 / 機台 z-score / × 刀具參考(VB 50–60) | T3、T4 |
| VB 門檻 | 滑桿,範圍 60–150 µm,預設 140 | T2、T7 |
| 異常門檻 | 滑桿,robust |z| 3–10,預設 6 | T5 |

### 色彩
- **顏色只代表機台(3 類)**:M1 `#2a78d6` 藍、M2 `#eb6834` 橘、M3 `#1baf7a` 青綠。
  已用 dataviz 驗證腳本檢查(所有配對比較):色盲 ΔE 最差 9.2(≥ 8 通過),一般視覺 ΔE 最差 24.0(通過)。
  青綠色對背景的對比只有 2.74 : 1(< 3 : 1),因此**一律搭配直接文字標籤和圖例**。
- **刀具不用顏色區分**(9 色會超出可分辨的上限):用小倍數圖的位置、文字標籤和 hover 來辨識。
- **相關係數熱圖**:發散色階(藍 − 灰 − 紅),中點 ρ = 0 為中性灰,對應「負相關 / 無關 / 正相關」。
- **選取或高亮**:非選取項目淡化(降低不透明度),不額外引入新色相。異常點用黑色外框表示,不用狀態紅,以免和機台色混淆。

### 資料限制的標示(誠實)
- 磨耗曲線上只畫實際的 run 點;tooltip 註明「VB 大多為內插值」。
- T8 的磨耗曲線起點從 VB 34 µm 開始,並加註「缺磨合期」。
- M2 的主軸扭矩和進給出力:加註「可能混疊」。
- T7、T8 的進給軸和位置誤差:加註「座標旋轉 1–2°」。
- 壽命和批次:圖說加註「M2 = 刀具批次 B,與機台效應混淆」。

## 方案 A:單頁連動儀表板(線框圖 A)
| 視圖 | 資料 | Mark / Channel | 為什麼這樣選 | 考慮過的替代方案 | 任務 |
|---|---|---|---|---|---|
| V1 磨耗曲線小倍數(3×3) | 每刀 VB vs C | 折線 + 小點;x = C、y = VB(位置);顏色 = 機台;列 = 機台 | 時間趨勢用位置編碼最準確;小倍數圖避免 9 條線重疊;同一列 = 同一機台,方便比較 | 9 線疊在一張圖(重疊嚴重,但適合看機台群組差異,可做成切換) | T1 |
| V2 門檻壽命長條 | 各刀達到門檻的 C | 水平長條,依機台分組;可拖曳的垂直線 = 固定換刀時間;標註浪費 % | 比較「長度」用對齊基線的長條最準確 | 點圖(較省墨,但浪費的區段不易表現) | T2 |
| V3 特徵排名熱圖 | Spearman ρ(特徵 × 刀) | 矩形格;顏色 = ρ(發散色階);依「全部刀」排序 | 23 × 10 的矩陣,用熱圖能一眼看出機台區塊(例如 M3 的 A_tooth 為負) | 長條圖排名(只能顯示一欄) | T3、T4 |
| V4 特徵 vs VB 散佈 | 每個 run | 點;x = VB、y = 特徵;顏色 = 機台;低不透明度加每刀滾動中位數線 | 看相關性和跨機台是否重疊;6,418 點有重疊問題,所以用低不透明度和中位數線 | 六角分箱(會失去機台身分) | T4、T5、T7 |
| V5 刀具 run 時序 | 選定刀的特徵 vs run | 點 + 線;交替底色 = 層;異常外框 | 層內效應和換層跳動只在時序中看得出來 | 不另外做(資訊會遺失) | T5 |
| V6 run 下鑽 | 選定 run 的訊號 | 小倍數折線圖,共用時間軸:機台訊號 + 測力計參考 | 不使用雙軸,兩種量綱分成上下兩張圖 | 雙軸疊圖(依設計規範禁止) | T6 |

**連動**:V1 的時間刷選 → V3 和 V4 只看該區段(V3 即時重算 ρ);V4 的 2-D 刷選 → V1 和 V5 高亮;點擊 V3 的某一列 → 切換 V4、V5 的特徵;點擊 V5 的 run → V6;任何地方點選刀具 → 所有視圖高亮。
**優點**:所有連動同時可見,最符合 C5「動作會更新其他視圖」;demo 時一眼就看得懂。
**缺點**:6 個視圖擠在一頁,筆電畫面較緊;需要仔細排版。

## 方案 B:三步驟引導式工作流(線框圖 B)
- 分頁 ① 壽命與門檻(V1 疊線版 + V2)→ CH1
- 分頁 ② 選指標(V3 + 跨機台滾動中位數疊線)→ CH2
- 分頁 ③ 驗證異常(V5 + V6)→ CH3
- 左側常駐 9 條迷你曲線作為總覽,共用選取狀態。

**優點**:每頁只有 2 個主視圖,畫面清爽;分頁順序直接對應 CH1 → CH2 → CH3,報告和 demo 敘事很順。
**缺點**:跨分頁的連動看不到「即時更新」,C5 可能被質疑。每頁只有 2 個視圖加總覽,要靠總覽條補足「至少 3 個連動視圖」。

## 建議
**方案 A**,理由:C5(連動)和 C3(任務對應)是硬性評分點,A 最容易證明。B 的敘事優點可以用 A 加上「情境導覽按鈕」來取得:按下 ①②③ 時自動套用對應的控制設定並捲動到相關視圖。
