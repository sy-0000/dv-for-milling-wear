# 03 VA 邏輯鏈與視覺設計（報告第 2–6 節底稿）

> 刀具改稱 **E1–E9**（E = end mill），避免和任務 T1–T7 混淆。M1：E1–E3，M2：E4–E6，M3：E7–E9。
> 數字都可追溯到 `data/verify_expected.json`（`scripts/verify.py` 產生）或 `data/eda_*.csv`。

## 1. 資料能 / 不能回答

| 能 | 不能（寫進限制） |
|---|---|
| 各刀、各機台的壽命和磨耗階段 | 機台和刀具批次分不開（M2 = 批次 B） |
| 不同換刀規則（固定時間或訊號警示）的浪費和誤差 | 只有 9 把刀、每台 3 把，無法推廣 |
| 指標換一台機台是否還能用（留一台機台測試） | 分辨不出哪些 VB 是實測、哪些是內插 |
| 和換層同步、需要排除的訊號變化 | 異常的真正原因（沒有停機、裝夾紀錄） |

## 2. 使用者

在**多台機台**導入刀具監控的製程/設備工程師。產線上**只有機台控制器訊號**（主軸扭矩、進給出力、位置誤差）；導入前會做試驗（顯微鏡量 VB，可能外加測力計）。測力計在系統中只當**參考答案**。

## 3. 挑戰

- **CH1 該用哪種換刀規則？** 全廠固定時間、每台機台固定時間、訊號警示（全廠一個值或每台校正）。每種都在「浪費壽命」和「超過門檻」之間取捨。機台間壽命差約 1.5 倍，但同機台內到 140 µm 最多只差 3.4 分鐘 → 訊號規則要贏的是「每台機台固定時間」。
- **CH2 哪個產線訊號能當指標？能跨機台嗎？** 特徵與正規化方式很多；進給軸單位不同（Nm / N）、主軸扭矩正負號不同。正規化必須產線做得到（新刀沒有完整壽命、沒有顯微鏡）；單把刀內 ρ 會被內插 VB 高估。
- **CH3 訊號變化一定是磨耗嗎？** 刀每 1–2 層被拆下量 VB，換層時加工狀態可能改變；只看數值的警示分不出來。

**為什麼要 VA**：只有 9 把刀，模型推廣性無法驗證；規則與校正需要人在浪費、誤報、漏報間取捨；自動旗標只能說「哪裡怪」，要不要相信警示得看原始訊號、層結構和其他機台對照。

## 4. 任務

| ID | 任務 | 來自 |
|---|---|---|
| T1 | 概覽所有刀的磨耗曲線，比較各機台在哪個階段有差異 | CH1 |
| T2 | 在選定 VB 門檻下，比較不同換刀規則的未使用壽命和超限時間 | CH1 |
| T3 | 在不同正規化下，依和 VB 的 Spearman ρ 為特徵排名（可用時間範圍篩選） | CH2 |
| T4 | 比較同一特徵在三台機台正規化後的曲線，判斷能否跨機台 | CH2 |
| T5 | 找出層間跳動或層內上升超過門檻的層 | CH3 |
| T6 | 檢視選定 run 的訊號，比較旗標層和前一層，對照機台訊號與測力計 | CH3 |
| T7 | 用其他機台校正警示值、在第三台測試，讀出提早或延遲幾分鐘；測試延續條件的影響 | CH1 + CH2 |

## 5. 分析元件

- **A1 正規化**：產線可用（× 新刀前 3–6 分鐘），可切換比較只能用在試驗的方式（× VB 50–60 µm、機台 z-score、原始值）→ T3、T4
- **A2 即時 Spearman 排名**（隨正規化、時間刷選重算）→ T3
- **A3 換刀規則評估**：固定時間（全廠／每台／每台留一法，可拖曳）或訊號警示（只看過去 15 run 的滑動中位數；警示值手動、同機台校正或其他機台校正；延續條件）。所有規則用**同一個留一法測試、同一個摘要格式**；MAE 只算有警示的刀，漏報另外列 → T2、T7
- **A4 層級診斷**：層間跳動（J）、層內上升，門檻可調，顯示「被標記幾層」→ T5

## 6. 洞察（特徵 = 主軸扭矩，正規化 = × 前 3–6 分鐘，VB 門檻 140 µm）

- **I1（CH1）**：全廠固定 53.5 分鐘，M2 的刀浪費 34–36%；每台機台各訂時間平均浪費約 2%。公平比較（同機台留一法）：**MAE 1.7 min、3 次超限（≤ 2.0 min）、0 漏報**。⚠ 機台差異可能來自批次，但結論只需要「同機台的刀壽命一致」。
- **I2（CH2）**：主軸扭矩 9 把刀都隨磨耗上升（合併 ρ = 0.95，測力計 Force X 0.98）；門檻時約為新刀的 1.24–1.37 倍。
  - 用其他兩台校正：M1、M2 提早 5.8–14.7 min，**M3 三把全部漏報**（MAE 11.3 min）。
  - 同機台留一法：**MAE 4.7 min**（8 次警示）、1 晚（E3 2.7 min）、1 漏報（E5），仍輸固定時間的 1.7。
  - → **趨勢可以跨機台，警示值不行**；訊號警示最多當每台各自校正的安全網。
- **I3（CH3）**：E1 第 15 層扭矩整層跳高 19%（J），其他機台校正、延續 1 run 時警示在 42.2 min（VB 103）觸發，**早 12.3 min**；第 16 層回落 → 誤報。
  - 延續 29 run（一層）：44.6 min，仍早 9.9 min；**30 run 才濾掉**（早 0.5 min，VB 137），但同機台校正時 9 把有 5 把漏報 → 延續條件是誤報與漏報的取捨。
  - 預設門檻下 222 層只有 2 層被標記（E1 L15、E3 L0）→ 規則「**警示落在被標記的層 → 檢查，不直接換刀**」可行。E2–E9 的提早警示都不在被標記層，是警示值本身造成；排除 E1 後留一法 MAE 3.6 min，仍高於 1.7。
  - E9 第 10–14 層的層內上升：測力計 26–52%、主軸扭矩 5–7%；和 VB 100→140 間扭矩倍數只差約 0.06–0.09 相比不可忽略。

## 8. 色彩與誠實標示

- **顏色只代表機台**：M1 `#2a78d6` 藍、M2 `#eb6834` 橘、M3 `#1baf7a` 青綠（驗證見 `04_verification.md`）。青綠對白底只有 2.74 : 1 → 一律加文字標籤與圖例。
- 刀具不用顏色（9 色超過可分辨上限），用位置、文字和 hover。
- 唯一強調色（洋紅）只用在警示、標記和選取；非選取項目淡化。
- 資料限制標示：tooltip 註明「VB 大多為內插」；E8 曲線從 34 µm 起並註「缺磨合期」；M2 扭矩與進給註「可能混疊」；E7、E8 進給與位置誤差註「座標旋轉 1–2°」；圖說註「M2 = 批次 B，與機台混淆」；raw 模式進給軸提示「M1 為 Nm，M2/M3 為 N」。
