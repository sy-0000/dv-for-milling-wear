# 階段 3:可行性關卡(Q3 值不值得做?)

腳本:`scripts/feasibility_check.py --step 3`(每把刀每 3 個 run 抽 1 個,共 2,142 個 run)
輸出:`data/feasibility_features.csv`、`data/feasibility_spearman.csv`、`docs/figs/feasibility_scatter.png`

## 方法
- **切削區段**:用測力計 XY 合力的 50 ms 移動 RMS,超過其第 95 百分位數 30% 的區間視為在切削,頭尾再各裁掉 0.15 s。
  偵測到的切削長度為 3.91–4.05 s(平均 3.98),與「每個 run 讓 C 增加約 4 s」吻合,表示切段方法可信。
- **特徵**:每個 run 在切削區段內算 10 個統計量(合力平均與 RMS、各軸力標準差、主軸扭矩平均、進給軸扭矩或力、位置誤差標準差)。
- **相關**:每把刀各自算 Spearman ρ(特徵 vs VB);另外把 9 把刀合併,比較「特徵 vs VB」和「特徵 vs C」。

## 結果
| 特徵 | 每把刀 ρ 的中位數 | 9 把刀合併、各機台 z-score 後:ρ(VB) / ρ(C) |
|---|---|---|
| F_xy_mean(測力計合力平均) | 0.99 | 0.95 / 0.91 |
| T_spindle_mean(主軸扭矩平均) | 0.99 | 0.97 / 0.93 |
| axis_y_mean_abs(Y 軸進給扭矩或力) | 0.99 | 0.94 / 0.89 |
| F_y_std | 0.98 | 0.89 / 0.88 |
| pcd_y_std(Y 軸位置誤差標準差) | 0.98(T3 為 −0.10) | 0.80 / 0.78 |
| F_x_std、F_z_std | −0.61、0.33 | 不一致,方向因刀而異 |

## 解讀與注意事項
1. **有特徵,而且很強**:平均力和扭矩類特徵在 9 把刀上都隨 VB 單調上升。
2. **⚠️ ρ ≈ 0.99 會高估**:單一刀內 VB 是依 C 線性內插的,所以任何隨時間單調漂移的量(例如溫度、工件位置)都會得到高 ρ。
   比較有說服力的證據是:**跨機台合併後,特徵與 VB 的相關高於與 C 的相關**。M2 的刀要更長時間才磨到相同 VB,而特徵跟的是 VB,不是時間。不過兩者差距不大(約 0.04),只能算支持性證據,不是證明。
3. **機台訊號要依機台正規化**:主軸扭矩和進給軸訊號,三台機台的基準值差很多(M1 的進給軸是扭矩 Nm,M2/M3 是力 N,單位不同不能直接比)。
   測力計訊號三台的基準值大致重疊:同一種感測器、同樣的安裝方式。
4. **散佈圖有條紋或鋸齒狀的平行帶**,可能是同一層裡不同位置(tool_position_x)造成的系統性差異,待階段 5 確認。
5. **M2 的曲線形狀不同**:F_xy_mean 在 VB 50–100 之間特別陡,和 M2 磨耗曲線中段很長的平台期有關。是否受混疊或刀具批次影響,目前不確定。
6. 樣本只有 9 把刀,每台機台 3 把,跨機台的結論要保守。
