## 1. Data → Users
**目標使用者 ❓**(建議 A)
- **A. 負責在多台機台導入刀具狀態監控的製程/設備工程師。** 他們手上有每台機台控制器都能取得的訊號(主軸扭矩、進給出力),試驗時可以另外裝測力計、用顯微鏡量 VB。這份資料正是這種「導入前試驗」會收集到的東西。
- B. 刀具監控演算法的開發人員或研究者,也就是論文本身設定的讀者。
- 為什麼 A 合理:論文摘要直接點出現場的痛點,「刀具通常依固定時間更換,浪費大部分剩餘壽命」。而且「多台機台」正是這份資料的特色(論文 Value of the Data 第一點)。

## 2. Users → Challenges(為什麼難、為什麼需要 VA)
**CH1. 換刀時機難訂。** 同型號的刀,壽命隨機台不同,差異可達 50% 以上:到 VB 140 µm 時,M2 平均 83.0 分鐘,M1 56.3 分鐘,M3 53.8 分鐘。依固定時間換刀若要對所有刀都安全,就得遷就最短命的刀。但門檻本身是品質和成本之間的取捨,需要工程師判斷,沒有唯一解。
**CH2. 不知道哪個訊號可以當作磨耗指標,也不知道能不能跨機台使用。** 23 個特徵 × 9 把刀 × 多種正規化方式。單把刀內的相關係數會因 VB 內插而高估。同一個特徵在不同機台的行為可能相反(530 Hz 刀齒振幅在 M3 下降)。原始數值不能跨機台比較(主軸扭矩合併時 ρ 只有 0.57,依機台正規化後 0.97)。
**CH3. 訊號變化不一定是磨耗。** 有層內效應、換層時的跳動(T1 第 15 層)、規律的鋸齒(T9 第 10–14 層),以及已知的資料問題(M2 混疊、T7/T8 座標旋轉、時間偏移)。這些若沒被分辨出來,會造成誤報或錯誤的換刀判斷。分辨它們必須回頭看原始訊號,並對照兩套獨立的量測系統。

**為什麼不是…**
- **簡單查詢 / 單張靜態圖**:問題不是「哪把刀最耐用」這種單一答案,而是要在特徵、機台、門檻、正規化方式的組合中來回比較。而且使用者事先不知道會出現哪些異常(T1、T9 都是探索中才發現的)。
- **全自動演算法**:只有 9 把刀,模型無法驗證能否套用到新機台;VB 標籤大多是內插的;異常需要工程師解釋原因。工程師要把指標放到產線上之前,**必須看見證據、相信它**。VA 的角色是讓人驗證指標,而不是取代人做判斷。

## 3. Challenges → Low-level tasks
| 任務 | 類型 | 來自 |
|---|---|---|
| T1 概覽所有刀的磨耗曲線,比較各機台在哪個磨耗階段有差異 | overview / compare | CH1 |
| T2 設定 VB 門檻,找出每把刀達到門檻的時間,並計算固定時間換刀會浪費的壽命 | identify / derive | CH1 |
| T3 依相關係數為特徵排名,並可選擇刀具、機台、正規化方式 | rank / correlate | CH2 |
| T4 比較同一特徵在三台機台上正規化後的趨勢,判斷能否跨機台使用 | compare | CH2 |
| T5 找出偏離趨勢的 run 或層,定位它在時間軸和層結構中的位置 | detect outliers / locate | CH3 |
| T6 檢視選定 run 的原始訊號,對照測力計和機台訊號是否一致 | details on demand / verify | CH3 |
| T7 讀出「指標倍數 ↔ VB 門檻」的對應,作為不用顯微鏡的換刀依據 | correlate / derive | CH1 + CH2 |

## 4. 分析元件候選(C6)
1. **門檻 → 壽命與浪費計算**(使用者拖曳 VB 門檻,即時重算各刀達標時間、固定時間策略的浪費比例)→ T2
2. **正規化切換 + 即時重算 Spearman 排名**(原始值 / 機台 z-score / 刀具參考倍數;筆刷選取的子集也會重算)→ T3、T4
3. **去趨勢殘差 + robust z 異常偵測**(門檻可調,異常 run 會在各視圖高亮)→ T5

## 5. 已在真實資料中驗證、可做成使用情境的洞見
- **I1(CH1)**:如果整個廠區用同一個固定換刀時間,並以最早到達 VB 140 µm 的刀為準(53.5 分鐘),M2 的三把刀會浪費 **34–36%** 的壽命;改成每台機台各自訂時間,浪費就降到 0–6%。若以 VB 100 µm 為準,M2 會浪費 41–42%。
- **I2(CH2 → CH1)**:主軸扭矩換算成「相對於該刀穩定期的倍數」後,9 把刀在 VB 140 µm 時都落在 **1.20–1.32 倍**,VB 100 µm 時為 1.13–1.22 倍。測力計合力(1.40–2.40 倍)和進給出力(1.37–2.05 倍)的分散則大得多。所以「主軸扭矩上升約 20–30%」有機會當作跨機台、不用顯微鏡的換刀警示。⚠️ M3 的倍數偏低(1.20–1.24),而且只有 9 把刀,只能算一個值得驗證的假說。
- **I3(CH3)**:T1 第 15 層力和扭矩跳高 20–30%,T9 第 10–14 層每層鋸齒式上升約 40%。兩者都和換層同步,兩套訊號一致,而且磨耗不會倒退。如果只看單一指標,會誤以為磨耗突然加速,進而提早換刀。透過下鑽和比對才能看出它們和換層有關,而不是單純的磨耗。
