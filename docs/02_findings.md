## F1 🟢 壽命：M2 明顯較長，同機台內很一致（`wear_phases_by_machine.png` a）

| 機台 | 到 VB 100 µm（分鐘） | 到 VB 140 µm（分鐘） |
|---|---|---|
| M1（T1–T3） | 43.7（40.8–46.4） | 56.3（54.5–57.9） |
| M2（T4–T6） | 68.2（66.8–69.0） | 83.0（81.5–84.0） |
| M3（T7–T9） | 40.5（39.7–41.6） | 53.8（53.5–54.3） |

- M2 約多用 50–60% 的時間；同機台 3 把刀到 140 µm 最多只差 3.4 分鐘。
- 🔴 M2 = 批次 B，機台與批次混淆。🔴 M2 最大 VB 147–149 µm，所以表格用 140 µm。

## F2 🟢 三階段磨耗，差異在中段（`wear_phases_by_machine.png` b、c）

- 磨合期（0→50 µm）各機台平均約 5–8 µm/min（第一層約 13 µm/min）；穩定期（50→110 µm）M1 1.5、**M2 0.9**、M3 1.6 µm/min；加速期（110→140 µm）3.0–3.7 µm/min。
- 壽命差異幾乎全部來自**穩定期**。
- 🔴 VB 是內插值，每層速率是內插斜率，不是逐 run 的真實速率；T8 缺磨合期。

## F3 🟢 特徵隨磨耗單調上升，但 ρ 會高估（`eda_2_spearman_heatmap.png`）

- 每把刀 ρ ≥ 0.95：Fx_mean、Tsp_mean、ax_y_mean、Fy_mean（Fxy_mean、F3_mean 在 T8 只有 0.84）。Fx_std、Fz_std 方向因刀而異。
- 🔴 單一刀內 VB 由 C 線性內插，任何隨時間漂移的量都會得到高 ρ → 只能說明「有趨勢」。
- 🟡 較公平的證據：9 把刀合併、依機台正規化後 **ρ(VB) > ρ(C)**（Tsp_mean 0.97 vs 0.93、ax_y_mean 0.94 vs 0.89）。M2 要更久才磨到同樣 VB，特徵跟的是 VB 而非時間；但差距小、只有 9 把刀。

## F4 🟢 機台內建訊號必須依機台正規化（`eda_2` 右三欄）

- Tsp_mean：不正規化合併 ρ 0.57 → 機台內 z-score 後 0.97；ax_y_mean 0.33 → 0.94。三台起始值不同（進給軸還有 Nm / N 的單位差）。
- Fx_mean（測力計）不正規化就有 0.98：同一顆感測器、同樣裝法。

## F5 🟡 能否跨機台，因特徵而異（`walk_2_F5_normalization.png`）

- **主軸扭矩**：原始值在 VB 50–60 µm 時 M1 1.22、M2 1.35、M3 1.03 Nm，到 VB 135–150 為 1.58 / 1.77 / 1.27 → 絕對門檻不能跨機台（「1.5 Nm 就換」在 M3 永遠不會觸發）。除以各刀參考值後三台重疊，約 1.22–1.31 倍。
- **Fxy_mean**：M1、M2 約 2.2–2.6 倍，M3 只有 1.5–1.8 倍。
- **ax_y_mean**：三台斜率都不同。
- **A_tooth（530 Hz）**：M1/M2 上升 1.7–1.9 倍，**M3 反而降到約 0.74 倍**；runout_ratio 也相反。原因不明（M3 機台動態或 T7/T8 座標旋轉？）。
- → 「哪個特徵在哪台機台可信」需要人看圖判斷，這是 VA 的切入點。

## F6 🟡 層內效應：位置和時間分不開（`eda_4_position_effect.png`）

- 同一層內 M1 的 Fxy_mean 從 x = 11 到 150 mm 平均增加約 10%，Tsp_mean 約 4%；M2、M3 平均 < 3%，但個別段落可能很大（見 F7 的 T9）。
- 同一層內刀永遠由 x 小切到 x 大，**位置和層內時間完全同步**：可能是位置（工件、受力點），也可能是時間（升溫、量 VB 時停機冷卻），資料無法區分。
- 相對於磨耗造成的 2 倍以上變化，平均效應小，但會在散佈圖形成條紋、在時序圖形成和層同週期的鋸齒。

## F7 🟡 兩段「不像磨耗」的變化（`walk_3_F7_anomalies.png`、`eda_anomalies.csv`）

- **T9（M3）第 10–14 層（run 約 300–420，VB 73–98 µm）**：每層內 Fxy_mean 從約 360 N 升到約 570 N（+40% 以上），下一層開頭又掉回，**規律的層內上升、層間重置**。主軸扭矩同步鋸齒（相關 0.94，每層 +5–7%）。兩套獨立量測都看到 → 不是感測器故障；磨耗不會倒退 → 不全是磨耗。可能是換層停機造成熱狀態或裝夾改變（無紀錄可證）。
- **T1（M1）第 15 層（run 436–464，VB 約 101–107 µm）**：從第一個 run 起 Fxy 和主軸扭矩同時跳高約 20–30%，A_tooth 約 130 → 230 N，runout_ratio 約 0.13 → 0.08。第 16 層力回落，但頻率特徵不回原水準 → 刀發生持續改變（刃口崩缺或重新裝夾後偏擺？）。同時 VB 斜率 1.4 → 2.7 µm/min，僅為推測。
- **M2 主軸扭矩異常（T4–T6 共 24 個）**：🔴 可能混疊，只能標註；run 內扭矩 std/mean 中位數 0.216，介於 M1（0.186）和 M3（0.244），沒有特別大。
- 意義：只看單一特徵數字，會誤以為 T1 突然磨很快、T9 忽快忽慢；要看兩套訊號是否一致、是否和換層同步，才能判斷。

## F8 🔴 缺漏

- C 缺口 > 30 s 只有 T8 run 10（226 → 343 s）；其餘約 24 s 是正常刪除。
- T8 從 C = 177 s、VB = 34 µm 開始，缺磨合期。
- 層內 VB 是內插直線。

## 對問題設計的意義

| 原本問題 | 資料能回答到什麼程度 | 改寫成 |
|---|---|---|
| 何時換刀 | 可以，但門檻是外部給定 | CH1：用哪種換刀規則？（F1、F2） |
| 不同機台壽命差多少 | 可以，但和批次混淆 | 併入 CH1／CH2：差在哪個階段、特徵能否跨機台（F2、F5） |
| 哪些訊號和磨耗相關 | 可以，答案因機台而異，且有雜訊來源 | CH2：哪個訊號可信、能否跨機台（F3–F5）；CH3：變化是不是磨耗（F6、F7） |
